# 밸런스 보고서 — 0.7.0 (0.8.0 재측정은 6절)

이 문서의 수치는 모두 게임 밖(`lua5.1`)에서 엔진을 돌려 얻은 것이다. 실제 WoW 클라이언트에서 잰 값이 아니다.
원본 출력은 같은 폴더의 `sim_points-0.7.0.txt`, `sim_progress-0.7.0.txt`에 그대로 있다.

## 1. 방법

| 도구 | 하는 일 | 실행 |
|---|---|---|
| `Test/sim_points.lua` | 정해 둔 지점마다 "그 레벨대의 영웅·장비"로 스테이지를 3판씩 돌려 클리어 수, 전멸 수, 평균 클리어 시간, 분당 처치 수를 잰다. 전멸하면 어디서(웨이브·보스와 남은 체력) 졌는지 적는다. | `lua5.1 Test/sim_points.lua 3` |
| `Test/sim_progress.lua` | 새 게임을 단순한 규칙으로 8시간 플레이한다(상자는 바로 열고, 더 좋은 장비를 끼고, 편성·스킬 칸 룬을 먼저 모아 산다). | `lua5.1 Test/sim_progress.lua 480 war_prot 11` |

- 비교 기준 "원작 기준(분)"은 원작 오프라인 보상표의 시간당 클리어 수(ClearCount)를 분으로 바꾼 것이다(`research/04` 7.2절). 오프라인 보상은 직접 플레이보다 느리게 잡혀 있을 수 있으므로 **이보다 조금 빠르면 정상**으로 본다(설계 9.6절).
- 기준 파티: 방어 전사, 신성 사제, 화염 마법사, 사격 사냥꾼, 전투 도적(앞에서부터 인원수만큼). 영웅 레벨 = 스테이지 레벨, 장비 = 스테이지 레벨 이하의 가장 높은 장비 단계, 스킬은 레벨 ÷ 10까지 올리고 남는 점수는 패시브.
- 대표 장비 등급 [독자]: 일반 고급·희귀, 악몽 전설, 지옥 불멸, 고통 아르카나.
- 한계: 시뮬레이션 플레이어는 단순하다. 원작 영웅의 레벨별 실제 성능 자료가 없어 "우리 영웅이 원작 영웅과 같은 세기인가"는 직접 비교하지 못했다. 몬스터 쪽 수치는 원작 표와 같다(설계 9.2.1절, `Test/test_stages.lua`).

- 인원이 적은 구간(2-5를 2명, 3-5를 3명·4명)은 원작 기준보다 느리다(최대 2.8배). 편성 칸 룬을 사면 빨라진다. 원작의 편성은 3명까지라 이 구간은 원작에서도 2~3명으로 진행하는 곳이다.
- 원정과 낙스라마스는 스테이지 레벨이 40/65/90으로 고정이라, 높은 강도는 더 강해진 파티로 돌아와 깨는 구조다(원작과 같다).

## 5. 남은 문제 (고치지 않았거나 판단을 미룬 것)

1. **지옥 검은날개 둥지**를 대표 장비(Lv65 불멸)로 깨지 못한다. 원작의 지옥 액트 보스 자체가 초당 2,400~2,800 피해(타격당 1,400~1,900)를 주는데, 이 장비의 레벨 77 영웅 체력은 550~1,100이다. 패턴 보정은 이미 하한(0.08)에 닿아 있어 남은 차이는 원작 수치에서 온다. 원작에서 이 보스가 원래 이만큼 높은 관문인지, 우리 영웅이 원작보다 약한지는 자료가 없어 판단하지 못했다.
2. **고통 원정 강도 20과 고통 낙스라마스 3**은 101레벨·신성/우주 장비로도 깨지 못한다(룬·유물·큐브 부착 없이 잰 값). 원작에서도 최상위 콘텐츠다.
3. 혼자일 때(1-2~1-5) 전멸이 잦다. 스킬 점수를 쓰고 첫 상자 장비를 끼면 줄어든다. 처음 몇 분의 안내는 화면에서 보완할 여지가 있다.
4. 원정 보급품의 최대치·소모·충전(100 / 분당 1 / 10분당 1)과 부식 수치는 원작 수치를 찾지 못해 정한 값이다.
5. 원작 1.2.0 이후 추가된 룬 노드(원정 전용 상자·보관·자동 개봉 등 50여 개)는 노드 단위 자료(비용·연결)를 구하지 못해 넣지 않았다. 원정 상자는 일반 지역 상자의 룬 효과를 그대로 받는다.
