## 1. 전체 구조

애드온 이름은 임시로 `WIH`다. 게임은 세 층으로 나뉜다.

| 층 | 내용 | WoW API 의존 |
|---|---|---|
| 데이터 | 영웅·스킬·아이템·몬스터·스테이지·룬·유물·표(경험치, 스테이지 레벨 배율 등) | 없음 |
| 엔진 | 능력치 계산, 전투 시뮬레이션, AI, 보상, 성장, 인벤토리, 큐브, 저장 데이터 검증 | 없음. Lua 5.1 표준 기능만 사용 |
| 표현 | 창, 화면, 전투 장면, 툴팁, 입력 | 있음 |

- 엔진은 게임 밖 `lua5.1`에서 그대로 실행된다. 자동 테스트와 밸런스 시뮬레이션은 이 방식으로 돌린다.
- 화면은 엔진의 상태를 읽기만 한다. 화면에서 따로 계산한 수치를 표시하지 않는다. 툴팁의 수치는 엔진이 쓰는 데이터와 같은 함수에서 나온다.
- 난수는 엔진 내부의 시드 기반 생성기를 쓴다(`math.random` 미사용). 같은 시드와 같은 입력이면 전투 결과가 같다.

### 1.2 시간과 실행

- 엔진은 고정 간격 **0.05초 틱**으로 전진한다 [독자: 원작의 틱 길이는 미확인].
- WoW 접속 중에는 창이 닫혀 있어도 프레임마다 지난 시간만큼 틱을 돌린다. 한 프레임에 쓸 수 있는 계산 시간에 상한을 두고, 밀린 틱은 다음 프레임들에서 따라잡는다.
- 실제 WoW 전투 중이거나 인스턴스 안일 때 계산을 늦추거나 멈추는 선택 항목을 설정에 둔다(기본: 계속 진행).
- WoW를 끈 동안은 실행되지 않는다. 그 시간은 재접속 때 오프라인 보상으로 정산한다(11절).

## 3. 능력치

### 3.1 합산 [원작]

```
최종값 = (기본값 + Σ Flat) × (1 + Σ Increased) × Π(1 + 각 More)
```

- 수정치의 출처: 영웅 기본값, 장비(기본·고정·고유·장식·세공·각인), 스킬 트리 패시브, 룬, 펫, 유물, 상태 이상, 버프 스킬, 환경(난이도 페널티).
- 데이터의 정수 단위는 원작과 같다: 공격속도·시전속도 ÷100, 확률·% 계열 ÷10(퍼밀), 스킬 계수 ÷10 = %, 원소 저항은 그대로 %p, 초당 재생 ÷100.

- 공격: 공격력, 공격속도, 시전속도, 치명타 확률·피해, 속성별 피해 %(물리·화염·냉기·번개·암흑), 전달 방식별 피해 증가(근접·투사체·광역·소환), 속성별 추가 피해, 연속 타격, 투사체 수, 투사체 속도, 범위, 사거리

## 4. 전투 규칙

### 4.1 전장 [원작 구조 / 독자 수치]

- 가로 한 줄. 영웅은 편성 순서대로 서서 오른쪽으로 걸어가 웨이브를 만나 싸우고, 다 잡으면 다음 웨이브로 이동한다. 스테이지 = 웨이브 여러 개 + 마지막 보스.
- 거리 단위는 원작의 사거리 수치를 그대로 쓴다(근접 120~170, 원거리 900~1100, 스킬 150~1650).
- 이동: 초당 이동 거리 = 이동속도 × 0.25 [독자]. 웨이브 사이에는 파티 전체가 가장 느린 구성원의 속도로 이동한다 [원작].
- 편성 순서 규칙 [독자]: 영웅 쪽 유닛은 자기보다 앞 순서인 살아 있는 아군을 앞질러 가지 못한다. 근접 영웅은 사거리와 상관없이 대상에게 거리 100까지 붙으므로 근접 영웅들은 선두와 같은 자리에 선다. 원거리 영웅은 사거리의 90% 거리에서 멈춘다.
- 몬스터는 가장 가까운 상대를 공격하고, 거리 차이가 30 이하면 편성 순서가 앞인 쪽을 공격한다. 그래서 같은 자리에 선 근접 영웅 중에서는 1번이 맞는다.
- 웨이브 간 거리 1,500, 웨이브 내 몬스터 간격 60 [독자].

### 4.2 공격과 스킬 [원작]

- 기본 공격: 초당 횟수 = `(영웅 기본 + 주무기 Flat) × (1 + Σ Increased) × Π(1 + More)`, 간격 = 1 ÷ 횟수. 계수 100%.
- 스킬 발동 방식은 네 가지다.

| 방식 | 규칙 |
|---|---|
| 기본 공격 | 계수 100% |
| 기본공격 N회마다 | 공격속도와 "기본공격 횟수 요구 감소"가 빈도를 정한다. 재사용 감소는 무관 |
| 재사용 시간 | N초마다. 재사용 감소(상한 75%)와 시전속도가 충전을 앞당긴다 |
| 상시 오라 | 장착하는 동안 항상 적용 |

- 유효 재사용 시간 = 기본 재사용 × (1 − 재사용 감소) ÷ 시전속도 배율 [독자: 원작의 결합식은 미확인]
- 자원은 없다. 준비된 스킬은 우선순위 순으로 쓴다. 단, 스킬마다 **사용 조건**을 가진다(4.8절).
- 스킬 레벨: 포인트로 Lv5까지, Lv6~10은 장비의 "모든 스킬 레벨"로만 [원작]. 계수는 레벨마다 선형 증가.

### 4.3 주는 피해 [원작 / 추정]

```
1타 피해 = 공격력 × 스킬 계수
          × (1 + Σ 해당 속성 피해 %)
          × Π(1 + 해당 전달 방식 증가 %)      근접·투사체·광역·소환. 스킬이 둘에 해당하면 둘 다 곱한다 [독자]
          × (치명타면 치명타 피해)
          × (1 + 대상의 받는 피해 증가 합)      상태 이상·디버프
```

- 치명타는 타격마다 굴린다. 광역 피해에도 적용된다 [원작]. 지속 피해에는 적용하지 않는다 [독자].
- 장비의 "추가 피해 +X"는 타격마다 더하는 고정 피해로 처리한다 [독자: 원작 해석이 갈림].
- 몬스터에게는 방어도·저항이 없다 [추정]. 보스의 "피해 감소 상태"는 스킬로 구현한다.

### 4.4 받는 피해 [원작]

1. 회피(물리) 또는 원소 회피: 성공하면 0
2. 막기 또는 원소 막기: 성공하면 절반
3. 방어도(물리) 또는 저항(원소)
4. 피해 감소: 전체와 속성별을 각각 곱한다
5. 피해 흡수: 고정 수치를 뺀다
6. 최소 1

```
방어도:  K = 14 × 스테이지 레벨 + 12
         경감률 = Armor² / (Armor² + K × (Armor + 0.4 × 피해)),  상한 0.85(근접) / 0.75(원거리)
저항:    유효 저항 = 속성 저항 + 모든 원소 저항 − 난이도 페널티(0 / 20 / 40 / 60), 상한 = 최대 저항
         받는 피해 = 피해 × (1 − 유효 저항 / 100).  음수면 그만큼 더 받는다
```

- 회피와 막기는 따로 굴린다. 회피 판정이 먼저다 [독자: 원작의 굴림 방식은 미확인].
- 모든 원소 저항은 화염·냉기·번개에만 적용하고 암흑에는 적용하지 않는다 [추정: 원작 출처가 갈림. 암흑을 따로 챙겨야 하는 쪽을 택함].
- 보호막(총량형)은 1번보다 앞에서 깎이지 않고, 6번까지 계산한 최종 피해를 체력 대신 흡수한다 [독자].

### 4.5 상태 이상 [원작]

| 이름 | 지속 | 효과 | 재적용 |
|---|---|---|---|
| 냉각 | 4초 | 공격속도·이동속도 30% 감소(More) | 시간 초기화 |
| 빙결 | 1.5초 | 행동 불가 | 걸린 동안 무효 |
| 점화 | 4초 | 화염 지속 피해 + 화염 피해 20% 더 받음 | 걸린 동안 무효 |
| 감전 | 6초 | 번개 지속 피해 + 번개 피해 20% 더 받음 | 시간 초기화 |
| 출혈 | 7초 | 물리 지속 피해 + 물리 피해 20% 더 받음 | 걸린 동안 무효 |
| 기절 | 2초 | 행동 불가 + 모든 피해 10% 더 받음 | 시간 초기화 |

- 지속 피해: 0.5초마다, 건 쪽 공격력 기준. 틱당 계수는 점화 25%, 출혈 15%, 감전 20% [독자: 원작의 계수·간격은 미확인].
- 암흑 지속 피해(독·저주·고통)는 상태 이상이 아니라 스킬이 대상에게 붙이는 **부착형 지속 피해**로 구현한다. 계수·지속·중첩 한도는 스킬이 정한다 [독자: 원작에는 영역형·회전형 지속 피해만 있음].
- 보스는 빙결·기절의 지속이 절반이다 [독자].
- 영웅도 몬스터에게서 상태 이상을 받을 수 있다(레이드 보스 패턴). 군중 제어 지속 감소(유물)가 적용된다.

### 4.6 소환물과 설치물 [원작 구조 / 독자 세부]

- 종류: 포탑형(고정 위치, 자기 공격 주기), 추종형(야수·악마·로봇: 이동하고 근접 또는 원거리 공격), 영역형(지면에 깔리는 피해·회복·흡수 영역), 덫(접촉 또는 조건 충족 시 폭발), 드론(아군을 감시해 회복).
- 각 소환물은 자기 공격 주기, 지속시간, 대상 선정, 최대 개수를 데이터로 가진다. 피해 = 시전자 공격력 × 계수 × (1 + 소환 피해 증가). 시전자의 속성 피해 %와 치명타를 계승한다 [독자]. 연속 타격은 계승하지 않는다 [원작].
- 추종형과 포탑형은 체력을 가진다. 체력 = 시전자 최대 체력 × 계수 [독자]. 몬스터의 대상이 될 수 있고, 죽으면 재사용 시간 뒤 다시 소환된다. 영역·덫·드론은 공격받지 않는다.
- 소환물은 편성 칸을 차지하지 않는다.

### 4.7 회복, 보호막, 사망 [원작 / 독자]

- 회복 스킬의 기준은 스킬마다 정한다: 대상 최대 체력의 %(원작의 Heal), 초당 고정량(원작의 Sanctuary), 시전자 공격력 계수. "회복량 증가"가 곱해진다.
- 생명력 흡수, 타격당·처치당 회복, 초당 재생 [원작].
- 사망한 영웅은 파티에 남고 **15초 뒤 최대 체력의 50%로 부활**한다 [독자: 원작은 부활 시간의 존재만 확인]. 부활 스킬과 빈사 회피 스킬은 원작과 같은 형태다.
- 전멸하면 스테이지 실패. "실패 시 자동 재시도"가 켜져 있으면 같은 스테이지를 다시 하고, 꺼져 있으면 이전 스테이지로 내려간다 [추정]. 실패 페널티는 없다.

### 4.8 대상 선정과 AI [독자: 원작 규칙 미확인]

`AI/Targeting`은 교체 가능한 모듈이다.

- **몬스터**: 사거리 안에서 가장 가까운 영웅 또는 추종형 소환물. 한 줄 전장이므로 선두가 맞는다. 원거리 몬스터의 광역 공격은 대상 주변 반경 안의 영웅을 함께 맞힌다. 보스 패턴은 패턴마다 대상을 지정한다(선두, 무작위, 체력 최저, 후열, 전원).
- **영웅 기본 공격**: 가장 가까운 적.
- **영웅 스킬**: 스킬 데이터의 대상 규칙을 따른다(가장 가까운 적, 체력 최고·최저 적, 가장 밀집한 곳, 체력 비율 최저 아군, 쓰러진 아군, 자신, 전원).
- **스킬 사용 조건**: 스킬마다 기본 조건을 가진다. 예: 치유는 대상의 체력 비율이 기준 이하일 때, 광역기는 범위 안 적이 2명 이상일 때, 생존기는 자신의 체력 비율이 기준 이하일 때, 강화 버프는 보스나 적 다수일 때. 조건이 충족되지 않으면 스킬을 아끼고 다음 우선순위로 넘어간다.
- 영웅별 전투 설정에서 스킬 우선순위와 조건 기준값(체력 비율 등)을 바꿀 수 있다. 기본값은 영웅 설계가 정한다.
- 탱커: 위협 수준이 없으므로 선두에 서는 것이 탱킹이다. 탱커 영웅은 선두에서 버티는 능력(막기·피해 감소·보호막)과 파티를 지키는 효과(주변 아군이 받는 피해의 일부를 대신 받기, 흡수 영역, 파티 피해 감소 오라)를 가진다.

### 4.9 전투력 표시 [독자]

원작은 "기본 공격 DPS"만 보여 준다. 이 프로젝트는 영웅마다 다음을 표시한다.

- 예상 DPS: 표준 허수아비 전투(단일 대상 60초, 3대상 30초)를 엔진으로 돌린 평균
- 예상 HPS: 표준 피해 상황에서의 초당 유효 회복량과 보호막량
- 유효 체력: 현재 스테이지 레벨의 기준 물리·원소 타격에 대해 버틸 수 있는 피해 총량
- 종합 전투력 = 위 셋을 역할 가중치로 합친 값. 가중치와 표준 전투의 정의는 공식 설명서에 적는다.

장비나 스킬이 바뀔 때만 다시 계산하고 결과를 저장한다.

### 6.4 아이템 표의 생성 [원작 구조 / 독자 표]

- 장비는 (종류, 아이템 레벨, 등급)마다 **하나의 아이템**이고 능력치가 고정이다. 드롭할 때 굴리지 않는다 [원작].
- 한 아이템의 능력치는 네 층이다: 기본 능력치(종류가 정함) / 고정 능력치(등급에 따라 0~3줄) / 고유 능력치(아르카나 이상 일부) / 큐브로 붙이는 줄(장식·세공·각인).
- 표를 만드는 규칙:
  - 기본 능력치 수치는 원작의 레벨·등급 곡선을 따른다(`research/02` 3.3절). 새 무기 종류는 가장 가까운 원작 종류의 곡선을 쓴다.
  - 고정 능력치는 종류별 능력치 풀(`research/02` 4.2절)에서 고르고, 수치는 풀의 범위 안에서 레벨·등급에 비례해 정한다. 새 종류의 풀은 사용 영웅의 역할에 맞춰 원작 풀을 조합해 정한다.
  - 한 아이템에 같은 (능력치, 연산)이 두 번 붙지 않는다 [원작].
  - 표는 개발 시점에 스크립트로 한 번 생성해 데이터 파일로 고정한다. 게임 실행 중에는 바뀌지 않는다.

## 7. 드롭과 보물상자 [원작]

- 몬스터는 아이템을 직접 주지 않는다. 일반 몬스터는 처치당 확률로 **일반 상자**를, 스테이지 보스는 **스테이지 상자**를, 레이드(액트 보스)는 **레이드 상자**를 준다.
- 드롭 확률: 일반 상자 16% → 2%(일반 난이도, 구간이 오를수록 하락), 악몽 1.5% / 지옥 1.0% / 고통 0.8%. 스테이지 상자 100% → 20%, 악몽 15% / 지옥 10% / 고통 8%.
- 획득 허용량: 상자 종류별로 N분에 1개씩 충전되는 허용량이 있어야 상자가 떨어진다. 기준 시간은 원작과 같다(스테이지 레벨 15 이상: 일반 3분, 스테이지 5분. 원정: 4분, 6분). 허용량의 누적 한도는 2개 [독자: 원작 한도 미확인]. 접속하지 않은 동안에는 충전되지 않는다 [독자].
- 상자는 종류별 보관함에 쌓인다. 기본 보관 한도 5개 [추정], 룬으로 확장. 자동 개봉(룬으로 해금, 일반 300초 / 스테이지 600초 / 레이드 60초)과 일괄 개봉 [원작].
- 상자 1개 = 가중치 표에서 보상 1개. 표는 상자 종류와 스테이지 레벨대별로 장비(종류·레벨·등급)와 재료의 가중치를 가진다. 원작의 등급 분포를 따른다(`research/02` 6.5절). 천상 이상은 레이드 상자, 원정, 합성에서만 나온다. 장신구는 레이드 계열 상자에서만 나온다.
- 드롭 확률을 올리는 수단은 룬과 펫뿐이다.

### 9.6 5인 기준 재조정 [독자]

원작의 몬스터 수치는 3인 파티와 장착 스킬 2칸을 전제로 한다. 이 프로젝트는 5인·4칸이므로 스테이지 레벨 배율표의 체력·공격력 열에 **보정 계수**를 곱한다.

- 계수는 스테이지 레벨의 함수다. 편성 칸이 열리는 시점(1 → 2 → 3 → 4 → 5칸)에 맞춰 1에서 최종값까지 올라간다.
- 산출 방법: 기준 파티(탱커 1, 힐러 1, 딜러 3. 그 스테이지 레벨대의 기준 장비)를 엔진으로 돌려, 원작 오프라인 보상표의 시간당 처치 수·클리어 수(`research/04` 7.2절)를 기준 속도로 삼아 그보다 조금 빠르게 클리어하도록 체력 계수를 정한다. 공격력 계수는 기준 파티의 사망률이 목표 범위에 들어오도록 정한다.
- 골드·경험치 배율은 건드리지 않는다. 처치 수가 같으므로 경제는 원작과 같은 속도로 흐른다.
- 결과 계수와 시뮬레이션 수치는 밸런스 보고서에 싣는다.

- 10종. 전투에 참여하지 않고, 보유만 하면 효과가 항상 적용되며 전부 중첩된다. 효과는 경험치·처치 골드·상자 드롭 확률 계수.
- 획득: 5종은 특정 몬스터 5,000마리 처치 [원작]. 원작의 유료 3종은 업적 보상으로, 이벤트 2종은 레이드 몬스터 처치 누적으로 바꾼다 [독자].
- 외형은 WoW의 애완동물로 한다.

### 10.3 유물 [원작]

- 원정을 한 번 클리어하면 열린다. 유물함 최대 2개 장착(두 번째 칸은 지옥 원정 강도 10 클리어).
- 유물함: 등급별 칸 0~8개, 고정 속성 1~3줄(9종 풀), 칸마다 색. 유물: 36종 × 10등급, 5색, 같은 색 칸에만(흰색은 아무 칸).
- 공명: 유물함마다 색 조합 조건과 효과를 가진다. 모든 효과는 파티 전원에게 적용된다.
- 획득: 원정 상자의 재료 → 큐브 기원. 조율로 칸 색과 수치를 다시 굴린다.
- 유물함 62종의 공명 효과는 원작의 조건·수치 구조를 따르되, 특정 스킬을 가리키는 효과는 30영웅의 스킬에 맞게 다시 지정한다.

## 11. 경제와 오프라인 보상 [원작]

- 재화는 **골드** 하나다. 실제 WoW의 골드와 구분되도록 화면에서는 전용 아이콘과 "W.I.H 골드"로 표기한다.
- 획득: 몬스터 처치(기본 골드 × 스테이지 레벨 골드 배율, 보스 배율), 연금술, 오프라인 보상.
- 소비: 룬(전체 약 100억), 영웅 해금, 인벤토리·보관함 칸, 큐브 레시피 해금, 기원, 제거, 조율.
- 클리어 보너스는 없다. 보상은 전부 처치에서 나온다.
- 오프라인 보상: 룬으로 해금(100골드). 골드와 경험치만. 최대 8시간. 30일 이상이거나 시각이 거꾸로 가면 0. 기준은 마지막으로 진행하던 스테이지의 레벨. 계산은 원작의 오프라인 표(스테이지 레벨별 기본 골드·경험치·시간당 처치 수)와 오프라인 룬 보너스를 쓴다. 경험치에는 레벨 차 페널티를 적용한다.
- 원정 보급품은 오프라인 중에도 충전된다.

## 12. 저장

- `## SavedVariables: WIH_DB` (계정 공용). 최상위 구조:

```
WIH_DB = {
  schema = <정수>,            -- 저장 형식 버전
  createdAt, savedAt,         -- 서버 시각
  faction = "Alliance" | "Horde",
  settings = {...},
  gold, cube = {level, exp, recipes}, supply = {value, at},
  heroes = { [heroId] = {unlocked, level, exp, tree = {...}, equipped = {...}, skillBar = {...}, combat = {...}, form} },
  party = {heroId, ...},
  bag = {...}, stash = {...}, overflow = {...}, materials = {...},
  chests = {...}, buckets = {...},
  runes = {...}, pets = {...}, relics = {...},
  stage = {current, difficulty, cleared = {...}, repeatMode, autoRetry},
  stats = {...}, achievements = {...}, log = {...},
}
WIH_DB_BACKUP = { [n] = <이전 저장본> }   -- 최근 3개
```

- 저장 시점: 로그아웃·UI 새로고침 직전(`PLAYER_LOGOUT`), 그리고 5분마다 메모리의 상태를 `WIH_DB`에 반영한다. 클라이언트는 로그아웃 때만 파일로 쓴다.
- 불러올 때: 형식 버전을 확인해 단계별 변환 함수를 차례로 적용한다. 그다음 검증한다. 모르는 영웅·아이템·룬 참조는 버리고 기록한다. 수치는 허용 범위로 자른다. 형식이 깨진 항목은 기본값으로 바꾼다. 검증에서 문제가 있었으면 변경 전 저장본을 백업에 남기고 사용자에게 요약을 보여 준다.
- 아이템은 데이터의 아이템 ID와 큐브로 붙인 줄만 저장한다. 고정 능력치는 저장하지 않고 데이터에서 읽는다.
- 설정 화면에서 저장 데이터 요약 보기, 백업에서 복원, 전체 초기화를 제공한다.

## 13. 화면

### 13.1 방향

어두운 차콜 배경, 흰색·밝은 회색 글자, 얇은 테두리, 일관된 간격, 직사각형 또는 약한 둥근 모서리. 색은 아이템 등급, 위험 상태, 진영 강조색에만 쓴다. 진영 강조색은 얼라이언스 청회색, 호드 암적색이다. 장식 문양·금색 테두리·발광 효과는 쓰지 않는다. 글꼴은 클라이언트의 한국어 기본 글꼴 객체를 상속한다.

### 13.2 구성

- 최상위 창 하나. 이동, 크기 조정, 위치·크기 저장, 최소화(원작의 작업표시줄처럼 전투 장면만 남긴 띠 모드).
- 왼쪽 세로 메뉴: 전투, 영웅, 편성, 인벤토리, 큐브, 성장(룬·펫·유물), 스테이지, 기록(업적·전투 기록·통계), 설정.
- 상단 띠: 현재 스테이지와 진행, 골드, 상자 수, 원정 보급품.

| 화면 | 내용 |
|---|---|
| 진영 선택 | 첫 실행 때. 얼라이언스 / 호드 |
| 전투 | 전투 장면, 파티 체력·스킬 상태, 몬스터 정보, 웨이브 진행, 최근 보상, 반복·자동 재시도 토글 |
| 영웅 | 30명 목록, 직업·전문화·역할, 레벨, 능력치 상세, 장비 10칸, 스킬 트리, 장착 스킬과 전투 설정, 전투력·DPS·HPS·유효 체력 |
| 편성 | 5칸, 순서 변경, 역할 요약, 파티 능력치와 오라 요약, 야성 드루이드 형태 선택 |
| 인벤토리 | 목록, 필터, 정렬, 장착, 비교, 잠금, 연금, 상세 툴팁, 보관함 |

| 기록 | 업적, 전투 기록, 통계 |

모든 버튼은 기능에 연결한다. 해금되지 않은 기능은 버튼을 숨기지 않고 잠금 상태와 해금 조건을 보여 준다.

### 13.3 전투 장면

- 가로 띠에 영웅, 소환물, 몬스터를 엔진의 위치대로 놓는다.
- 유닛 표시: 클라이언트 내장 3D 모델(`PlayerModel`). 대기·이동·공격·시전·피격·사망 동작을 엔진 이벤트에 맞춰 재생한다. 모델을 쓸 수 없는 환경이나 성능이 부족할 때는 **아이콘 토큰 방식**(직업·몬스터 아이콘 + 동작별 움직임)으로 바꾼다. 설정에서 고를 수 있고, 모델 표시 수에 상한을 둔다.
- 표시 요소: 체력 막대, 보호막, 상태 이상 아이콘, 피해·회복 숫자, 투사체, 영역, 포탑·드론, 사망, 보스 등장 알림. 효과는 내장 텍스처와 단색 도형으로 만들고 발광·과한 입자는 쓰지 않는다.
- 화면 갱신은 엔진과 분리한다. 창이 닫혀 있으면 그리지 않는다.

5. 지속 피해의 틱 간격과 계수, 부착형 지속 피해
6. 회피·막기의 굴림 순서, 보호막의 처리 순서
7. 소환물의 체력과 능력치 계승
8. 편성 4·5번째 칸과 스킬 3·4번째 칸의 비용
