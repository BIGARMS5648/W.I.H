# 구현·검증 현황

- 갱신일: 2026-11-22 (빌드 0.7.0)
- 이 문서는 무엇이 만들어졌고 무엇이 어떻게 확인되었는지를 기록한다. 새 작업을 시작할 때 먼저 읽는다.
- 설치용 ZIP: `dist/WIH-0.7.0.zip`(애드온 66개 파일 + TOC 2개). 압축을 푼 사본을 대역에서 불러와 게임 시작·전투·모든 탭 열기까지 오류 없이 도는 것을 확인했다(게임 밖 실행). 환경 점검 애드온: `dist/WIH_EnvCheck-0.1.0.zip`.
- 검증 구분
  - **게임 밖 실행** = Lua 5.1에서 자동 테스트로 실행함(`sh Test/run_all.sh`)
  - **대역 실행** = WoW API 대역(`Test/wow_stub.lua`) 위에서 화면 코드를 불러와 창을 열고 버튼을 눌러 봄. Lua 실행 오류와 규칙 연결은 확인되지만 **모양·배치·글자 잘림·실제 API 동작은 확인되지 않는다**
  - **시뮬레이션** = 게임 밖에서 엔진으로 긴 시간을 돌려 수치를 잰 것(`docs/balance/`)
  - **코드 검토만** = 실행해 보지 않고 코드를 읽어 확인한 것
  - **게임 내** = 포에버 클라이언트에서 사용자가 확인함

## 게임 내에서 확인된 것

- 환경 점검 애드온(`WIH_EnvCheck` 0.1.0)의 결과 1회. 내용은 `docs/research/07-envcheck-results.md`.
- 0.4.0: 사용자가 "원하는 인터페이스와 다르다"고 알려 줌 → 시안(`docs/design/mockups/ui-01-strip-and-menu.png`)을 승인받아 화면을 다시 만듦.
- 0.5.0: 메뉴 창과 모델 점검 화면이 뜨고, 생물 모델이 실제로 보이며, 한글이 나오는 것을 캡처로 확인. 12개 중 8개 모델이 비어 있었음. 요청: 영웅도 맞붙을 것, 장비에 따라 겉모습이 바뀔 것.
- 0.5.0 이후: 사용자가 "이동은 하는데 모션이 서 있는 모션"이라고 알려 줌 → 0.6.0에서 동작 고르기를 고침.
- **0.6.0과 0.7.0은 게임 내에서 실행된 적이 없다.** 확인 절차는 `docs/guide/first-build.md`.

## 알려진 문제와 주의

1. **게임 내 미검증**: 0.6.0 이후의 모든 화면(큐브·성장의 펫·유물·창고·원정 등)은 대역에서만 실행했다. 배치가 어긋나거나 글자가 넘칠 수 있다.
2. **밸런스**: `docs/balance/01-balance-report.md`. 대표 장비로 일반~고통 던전, 일반~악몽·고통 레이드는 깬다. **지옥 검은날개 둥지는 대표 장비로 못 깬다**(원작 액트 보스 자체의 피해가 큼). 고통 원정 강도 20·고통 낙스라마스 3은 최상위 장비로도 못 깬다(룬·유물 없이 잰 값).
3. 이름(던전·몬스터·보스·재료·유물)은 이 프로젝트가 지었거나 WoW 오리지널의 이름을 기억에 의존해 적었다. 클라이언트 표기와 대조가 필요하다.
4. 원작에서 확인되지 않아 정한 수치: 상자 허용량 한도 2·기본 보관 5, 원정 보급품(100 / 분당 1 / 10분당 1), 부식 수치, 기원 수수료 10골드, 편성 4·5칸과 스킬 4칸 룬 비용(500만·1억·300만), 부활 대기 15초, 보스 패턴 보정 방식, 레이드 체력 분배·보스 사이 회복, 시간 제한. 모두 `docs/design/03-formulas.md`에 [독자]·[추정]으로 표시했다.
5. `tools/import_*.py`의 입력(원작 추출 자료)은 저장소에 없다. 결과 파일(`WIH/Data/*.lua`)은 저장소에 있다.
6. 장비·재료 아이콘과 진영 문장은 클라이언트 내장 자산의 경로를 적은 것이다. 없는 경로는 물음표 아이콘으로 나온다.
