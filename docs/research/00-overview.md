## 6. 공개 자료로 확인하지 못한 항목

구현 시 독자 규칙으로 채워야 하며, 채운 값은 문서와 코드에 "독자 설계"로 표시한다. 원작 플레이로 확인한 자료가 있으면 교체한다.

1. 영웅·몬스터의 대상 선정 규칙(선두가 먼저 맞는다는 관찰만 있음)
2. 부활 대기시간의 길이
3. 유효 재사용 시간 식(재사용 감소와 시전속도의 결합), 시전 동작 시간
4. 지속 피해의 틱 간격과 계수
5. 회피·막기의 판정 순서, 기본 상한 75%의 원문 근거
6. 몬스터 체력·공격력의 절대 스케일(출처 계열에 따라 10배 차이. 상대 곡선은 확정)
7. 1.2.0 이후 추가된 룬 56노드의 개별 비용·선행 조건, 룬 초기화 기능의 존재 여부
8. 역병지대 오염도의 최대치·소모·충전 수치, 부식의 환산식, 역병 변이 몬스터 4종의 능력치
9. 보물상자 획득 허용량의 누적 한도와 기본 보관 수
10. 액트 보스 스킬의 세부 수치
11. 파티 내 경험치 분배 방식, 스킬 포인트 총량(레벨 N에서 N인지 N−1인지)
12. 소환수·포탑의 치명타·속성 계승, 체력, 기본 개수 제한
13. 포에버 클라이언트에서만 확인 가능한 것: 일반 프레임의 전투 중 조작 가능 여부, 자체 텍스처 형식(PNG 지원), 내장 아이콘 경로 해석, 생물 모델 ID, 저장 파일 크기 한계

## 8. 결정 대기 질문

추천안은 "원작 재현 우선" 원칙과 애드온 환경 제약을 기준으로 골랐다.

### 가. 게임의 틀

**Q1. 5인 파티의 구성원**
- (가) 애드온 내부 영웅 5명 — 추천
- (나) 실제 WoW 플레이어와 연동. 포에버는 인스턴스·전투 중 애드온 통신을 제한하므로 안정적으로 만들 수 없다.

**Q2. 실제 WoW 캐릭터와의 관계, 저장 단위**
- (가) 연동 없음. 진행 데이터는 계정 공용 1개(어느 캐릭터로 접속해도 같은 게임) — 추천
- (나) WoW 캐릭터마다 별도 진행
- (다) (가) + 첫 진영 선택 화면에서 접속 캐릭터의 진영을 기본 선택으로 제안

**Q3. 진영**
- Q3-1 직업 제한: (가) 없음, 양 진영 모두 10직업 — 추천(포에버 실제 규칙과 같음) / (나) 오리지널식(성기사 = 얼라이언스, 주술사 = 호드)
- Q3-2 진영 차이의 범위: (가) UI 강조색·명칭·영웅 외형만 — 추천 / (나) 콘텐츠 차이(던전 순서 등)도 둠
