# W.I.H 0.6.0 — 확인 안내

0.5.0에서 받은 캡처와 요청을 반영한 빌드다. 앞 빌드의 `WIH` 폴더를 지우고 새로 넣는다. 저장은 그대로 이어진다.

## 0.5.0에서 바뀐 것

1. **영웅이 적에게 달려가 맞붙는다.** 전에는 영웅이 제자리에 서 있고 몬스터만 다가왔다. 이제 새 웨이브가 나오면 영웅이 앞으로 달려 나가고, 화면이 뒤따라온다. 바닥의 작은 눈금이 흘러가는 것으로 이동을 알 수 있다.
2. **장비를 끼면 겉모습이 바뀐다.** 영웅을 종족·성별의 기본 캐릭터로 그리고, 낀 장비에 해당하는 옷과 무기를 입힌다.
   - 투구 → 머리, 갑옷 → 가슴·어깨·다리, 장갑 → 손, 신발 → 발, 주무기와 방패·보조 무기 → 손.
   - 겉모습은 아이템 레벨대에 따라 여섯 단계로 바뀐다(레벨 1~10 → 15~20 → 30~40 → 50 → 65 → 80~90). 등급에 따른 차이는 없다.
   - 장신구, 화살통·보주·고서 같은 보조무기는 겉모습에 나타나지 않는다.
   - **이 기능은 클라이언트의 "옷 입히기" 함수에 기대는데, 그 함수가 이 클라이언트에서 되는지는 아직 모른다.** 안 되면 자동으로 0.5.0의 고정 모델로 돌아간다.
3. **모델이 안 나오던 문제**: 보내 준 캡처에서 12개 중 8개가 비어 있었다. 2초 안에 안 뜨면 실패로 치던 것을, 0.7초마다 다시 요청하고 8초까지 기다리도록 바꿨다. 한 번 뜬 모델은 번호를 저장해 다음부터 바로 뜬다.

## 가장 먼저 확인해 주면 좋은 것

**설정 → 모델 점검**을 열면 첫 쪽이 "장비 룩"이다. 이 화면 캡처 한 장이면 대부분 알 수 있다.

- 화면 맨 아래에 **진단 줄**이 있다. `결과: 됨`인지 `안 됨(고정 모델로 대체)`인지, 그리고 `SetCustomRace`·`TryOn`이 `있음`인지가 적혀 있다.
- "장비 룩" 쪽의 열두 칸에 옷을 입은 캐릭터가 보이는가(전사·성기사의 단계별 옷).
- "영웅(고정 모델)" 쪽에서 지난번에 비어 있던 칸이 이번에는 채워지는가. 10초쯤 기다린 뒤에 캡처해 주면 좋다. 번호가 붉으면 그 번호는 끝내 나오지 않은 것이다.

사냥 띠에서는

- 영웅이 앞으로 달려 나가 적과 붙는가.
- 영웅이 오른쪽(적 쪽)을 보는가. 반대면 설정 → "방향 뒤집기".
- 공격·시전·쓰러질 때 동작이 바뀌는가.
- 가방에서 장비를 끼고 "지금 적용"을 누르면 띠와 영웅 화면의 캐릭터 모습이 바뀌는가.

## 화면 구조

- **사냥 띠**: 화면 아래에 늘 떠 있는 가로 띠. 영웅과 몬스터가 여기서 싸운다. 위쪽 줄에 스테이지·웨이브·골드·상자 수, 아래 줄에 진행 설정(누르면 켜고 끔)·초당 피해·최근 획득이 나온다.
  - 위쪽 줄을 끌면 옮겨진다. 오른쪽 아래 모서리를 끌면 폭이 바뀐다.
  - "접기"를 누르면 한 줄만 남는다. 채팅창에 `/wih 띠`를 입력하면 숨기거나 다시 보인다.
- **메뉴 창**: 띠의 "메뉴" 버튼이나 `/wih`로 연다. 닫아도 사냥은 계속된다. 탭: 영웅 · 가방 · 편성 · 스테이지 · 성장 · 기록 · 설정.
  - 큐브 탭은 큐브를 만들 때 넣는다.

## 설치

1. `dist/WIH-0.6.0.zip`의 압축을 푼다. `WIH` 폴더가 나온다.
2. 앞 빌드의 `WIH` 폴더를 지우고, 새 `WIH` 폴더를 `World of Warcraft\_camelot_\Interface\AddOns\`에 넣는다.
3. 게임을 완전히 껐다 켜고, 캐릭터 선택 화면의 애드온 목록에서 `W.I.H`를 켠다.
4. 접속하면 저장이 있을 때는 사냥 띠가 바로 뜬다. 처음이면 채팅창에 `/wih`를 입력해 진영과 첫 영웅을 고른다.

## 그다음으로 확인해 주면 좋은 것

오류가 나면 채팅창에 `W.I.H 오류:`로 시작하는 붉은 줄이 뜬다. 그 줄을 그대로 알려 주면 된다. 설정 화면의 "최근 오류"에도 남는다.

1. 사냥 띠와 메뉴 창이 시안(`docs/design/mockups/ui-01-strip-and-menu.png`)과 비슷하게 보이는가. 다른 곳은 어디인가.
2. 영웅 화면: 가운데 캐릭터, 양옆의 장비 10칸, 아래의 전투력, 오른쪽의 스킬·패시브·능력치가 제자리에 있는가.
3. 영웅 화면의 장비 칸을 누르면 가방으로 넘어가고, 가방에서 아이템을 오른쪽 클릭하면 장착되는가.
4. 띠를 옮기고 폭을 바꾼 뒤 `/reload`해도 그 자리에 있는가.
5. 글자가 칸을 넘치거나 겹치는 곳, 눌러도 반응이 없는 버튼, 물음표로 나오는 아이콘이 있는가.

**화면마다 캡처 한 장씩**(모델 점검의 장비 룩 쪽, 사냥 띠, 영웅, 가방)이 가장 도움이 된다.

## 들어 있는 것과 없는 것

| 들어 있음 | 아직 없음 |
|---|---|
| 영웅 30명과 스킬 180개, 스킬 트리, 장착 스킬, 전투력 표시 | 큐브(합성·제작·장식 등 10기능) |
| 편성(룬으로 최대 5칸) | 펫, 유물 |
| 액트 1~3의 던전 27구간과 보스 149종, 레이드 3종, 난이도 4단계 | 원정(줄구룹·안퀴라즈), 낙스라마스 |
| 장비 33종류(2,600여 개), 가방, 장착, 연금술(팔기) | 오프라인 보상 |
| 보물상자(드롭, 보관, 개봉, 자동 개봉 룬) | 고유 능력치가 붙은 장비 |
| 룬 200노드, 저장·백업·초기화 | 룬 트리 그림(지금은 목록) |

- 편성·스테이지·성장·설정 탭은 색과 창 구조만 새것이고 안의 배치는 이전 그대로다(시안에 없던 화면). 영웅·가방 탭과 사냥 띠의 방향이 맞으면 같은 방식으로 다듬는다.
- 난이도는 아직 조정 전이다. 원작보다 어렵거나 쉬운 구간이 있다.
