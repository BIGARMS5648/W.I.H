# W.I.H 0.8.0 — 설치와 확인 안내

"묻지 말고 끝까지 완성해 달라"는 요청에 따라 남아 있던 원작 시스템(1.2.0 이후 룬, 원정 상자 보관함, 공명 62종, 장비 고유 능력치)을 모두 넣은 빌드다. 앞 빌드의 `WIH` 폴더를 지우고 새로 넣는다. 저장은 그대로 이어진다(형식이 바뀌면 자동으로 변환한다).

## 설치

1. `dist/WIH-0.8.0.zip`의 압축을 푼다. `WIH` 폴더가 나온다.
2. 앞 빌드의 `WIH` 폴더를 지우고, 새 `WIH` 폴더를 `World of Warcraft\_camelot_\Interface\AddOns\`에 넣는다.
3. 게임을 완전히 껐다 켜고, 캐릭터 선택 화면의 애드온 목록에서 `W.I.H`를 켠다.
4. 접속하면 저장이 있을 때는 사냥 띠가 바로 뜬다. 처음이면 채팅창에 `/wih`를 입력해 진영과 첫 영웅을 고른다.

## 가장 먼저 확인해 주면 좋은 것

오류가 나면 채팅창에 `W.I.H 오류:`로 시작하는 붉은 줄이 뜬다. 그 줄을 그대로 알려 주면 된다. 설정 화면의 "최근 오류"에도 남는다.

1. **설정 → 모델 점검**의 "장비 룩" 쪽 캡처(진단 줄 포함). 옷 입히기 함수가 이 클라이언트에서 되는지가 여기서 나온다.
2. 사냥 띠: 영웅이 달려가 맞붙을 때 **달리기·공격 동작**이 나오는가, 영웅이 오른쪽을 보는가(반대면 설정 → "방향 뒤집기").
3. 새로 들어간 화면마다 캡처 한 장: **큐브**(합성 쪽), **성장 → 유물**, **스테이지 → 악몽 탭 → 원정**, **가방 → 창고**, **가방의 원정 상자**, 고유 능력치가 붙은 장비의 설명.
4. 글자가 칸을 넘치거나 겹치는 곳, 눌러도 반응이 없는 버튼, 물음표로 나오는 아이콘.

## 이번 빌드로는 확인되지 않은 것

- 0.6.0 이후 화면은 모두 **게임 밖 대역에서만** 실행했다. 실제 모양과 배치는 캡처를 받아 맞춘다.
- 모델 번호(영웅·보스·펫)와 겉모습 아이템 번호는 기억에 의존해 적었다. 다른 모습이 나오거나 비어 있으면 모델 점검 캡처로 바로잡는다.
- 밸런스 수치는 게임 밖 시뮬레이션의 결과다. 실제로 해 보고 너무 어렵거나 쉬운 곳을 알려 주면 조정한다.
