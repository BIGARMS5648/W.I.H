# W.I.H 0.4.0 — 첫 게임 내 빌드 확인 안내

이 빌드는 **화면과 진행이 실제 클라이언트에서 도는지** 보기 위한 시험용이다. 완성본이 아니다.
앞서 보낸 0.2.0과 0.3.0은 쓰지 않는다(화면 배치에 문제가 될 수 있는 부분을 고쳤고, 아이템·상자·레이드가 들어갔다). 앞 빌드로 만든 저장은 0.4.0에서 그대로 이어진다.

## 들어 있는 것과 없는 것

| 들어 있음 | 아직 없음 |
|---|---|
| 영웅 30명과 스킬 180개, 스킬 트리, 장착 스킬 | 큐브(합성·제작·장식 등 10기능) |
| 편성(룬으로 최대 5칸) | 펫, 유물 |
| 액트 1~3의 던전 27구간과 보스 149종 | 원정(줄구룹·안퀴라즈), 낙스라마스 |
| 레이드 3종(오닉시아의 둥지, 화산 심장부, 검은날개 둥지), 난이도 4단계 | |
| 장비 33종류(2,600여 개), 가방, 장착, 연금술(팔기) | 오프라인 보상 |
| 보물상자(드롭, 보관, 개봉, 자동 개봉 룬) | 3D 모델 전투 장면(지금은 아이콘 표시) |
| 룬 200노드, 저장·백업·초기화 | 고유 능력치가 붙은 장비 |

- 각 액트의 아홉 번째 던전을 처음 깨면 **용사의 증표**를 하나 받는다. 스테이지 화면에서 그 액트의 레이드를 골라 "레이드 시작"을 누르면 증표 하나로 도전한다. 레이드를 깨야 다음 액트(마지막 액트면 다음 난이도)가 열린다. 실패하면 증표는 쓰이지 않는다. 증표는 스테이지 상자에서도 낮은 확률로 나온다.
- 상자에서 재료도 나오지만 큐브가 없어 아직 쓸 곳이 없다. 가방 화면에 개수만 보인다.
- 몬스터의 세기·보상, 장비 수치, 상자 내용물과 확률은 원작의 값이다. 다만 **영웅 스킬의 수치와 5인 편성 난이도는 아직 조정 전**이라, 원작보다 어렵거나 쉬운 구간이 있다. 게임 밖 시뮬레이션(영웅 한 명, 단순한 규칙으로 투자)으로는 15분쯤에 다섯 번째 던전에 닿고 거기서 오래 머문다. 전멸해도 그때까지 잡은 몬스터의 골드와 경험치는 남는다.

## 설치

1. `dist/WIH-0.4.0.zip`의 압축을 푼다. `WIH` 폴더가 나온다.
2. `WIH` 폴더를 통째로 `World of Warcraft\_camelot_\Interface\AddOns\`에 넣는다(환경 점검 애드온을 넣었던 곳). 앞 빌드를 넣었다면 `WIH` 폴더를 지우고 새로 넣는다.
3. 게임을 완전히 껐다 켜고, 캐릭터 선택 화면의 애드온 목록에서 `W.I.H`를 켠다.
4. 접속해서 채팅창에 `/wih`를 입력한다.

환경 점검 애드온(`WIH_EnvCheck`)은 지워도 되고 그대로 두어도 된다.

## 처음 10분의 흐름

1. 진영과 첫 영웅을 고른다. 전투가 바로 시작된다.
2. 첫 던전을 깨면 **시작 무기**를 받는다. 가방 화면에서 그 무기를 오른쪽 클릭하면 장착된다. "지금 적용"을 누르면 바로 반영된다.
3. 몬스터를 잡다 보면 상자가 떨어진다. 가방 화면 아래에서 연다. 상자는 종류별로 5개까지 쌓이고, 일정 시간마다 받을 수 있는 수가 정해져 있다.
4. 레벨 2부터 스킬 포인트가 생긴다. 영웅 화면에서 스킬을 배우고 "장착"을 누른다.
5. 영웅이 레벨 3이 되면 룬을 살 수 있다. "스테이지 보스 추가 경험치" 다음의 "편성 칸"(1,000골드)을 사면 두 번째 영웅을 편성할 수 있다. 영웅 해금은 500골드다.

## 확인해 주면 좋은 것

오류가 나면 채팅창에 `W.I.H 오류:`로 시작하는 붉은 줄이 뜬다. 그 줄을 그대로 알려 주면 된다. 설정 화면의 "최근 오류"에도 남는다.

1. `/wih`로 창이 열리는가. 진영 그림과 글자가 보이는가.
2. 진영과 첫 영웅을 고르면 전투 화면으로 넘어가고, 영웅과 몬스터가 움직이며 싸우는가.
3. 피해 숫자, 체력 막대, 보스 등장 문구가 보이는가. 화면이 끊기지 않는가.
4. 영웅 화면에서 스킬에 포인트를 넣고, 장착하고, "지금 적용"을 누르면 스킬을 쓰는가.
5. 가방 화면에서 장비 아이콘이 보이는가. 장착·해제·팔기·상자 열기가 되는가.
6. 룬 화면에서 룬을 살 수 있는가(영웅이 레벨 3이 된 뒤).
7. 편성 화면에서 두 번째 영웅을 넣을 수 있는가(편성 칸 룬을 산 뒤).
8. 스테이지 화면에서 보스 정보가 보이고, 다른 던전으로 이동할 수 있는가. (아홉 번째 던전까지 갔다면) 레이드를 시작할 수 있는가.
9. 창을 닫아도(ESC 또는 닫기) 진행이 계속되는가. 다시 열면 골드와 레벨이 올라 있는가.
10. `/reload` 또는 재접속 뒤에 진행 상황이 그대로인가.
11. 글자가 칸을 넘치거나 겹치는 곳, 눌러도 반응이 없는 버튼, 물음표로 나오는 아이콘이 있는가.

화면 캡처를 화면마다 한 장씩 보내 주면 배치를 고치는 데 가장 도움이 된다.

## 환경 점검에서 남은 항목(선택)

지난번 점검에서 아래는 기록되지 않았다. 여유가 있을 때 `/wihcheck`에서 확인해 주면 3D 모델 전투 장면을 붙일 수 있다.

- "모델 16개 부하" 버튼을 눌렀을 때의 프레임율
- 모델이 실제로 눈에 보이는지, "동작" 버튼으로 움직임이 바뀌는지
- 전투 중에 창을 열고 닫았을 때의 기록(전투 한 번 뒤 `/wihcheck`)
