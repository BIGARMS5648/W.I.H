# W.I.H 0.5.0 — 다시 만든 화면 확인 안내

이 빌드는 **승인받은 시안대로 다시 만든 화면이 실제 클라이언트에서 어떻게 보이는지** 확인하기 위한 것이다. 완성본이 아니다.
앞서 보낸 0.2.0 ~ 0.4.0은 쓰지 않는다. 앞 빌드로 만든 저장은 0.5.0에서 그대로 이어진다.

## 화면 구조

- **사냥 띠**: 화면 아래에 늘 떠 있는 가로 띠. 영웅과 몬스터가 여기서 싸운다. 위쪽 줄에 스테이지·웨이브·골드·상자 수, 아래 줄에 진행 설정(누르면 켜고 끔)·초당 피해·최근 획득이 나온다.
  - 위쪽 줄을 끌면 옮겨진다. 오른쪽 아래 모서리를 끌면 폭이 바뀐다.
  - "접기"를 누르면 한 줄만 남는다. 채팅창에 `/wih 띠`를 입력하면 숨기거나 다시 보인다.
- **메뉴 창**: 띠의 "메뉴" 버튼이나 `/wih`로 연다. 닫아도 사냥은 계속된다. 탭: 영웅 · 가방 · 편성 · 스테이지 · 성장 · 기록 · 설정.
  - 큐브 탭은 큐브를 만들 때 넣는다.

## 설치

1. `dist/WIH-0.5.0.zip`의 압축을 푼다. `WIH` 폴더가 나온다.
2. 앞 빌드의 `WIH` 폴더를 지우고, 새 `WIH` 폴더를 `World of Warcraft\_camelot_\Interface\AddOns\`에 넣는다.
3. 게임을 완전히 껐다 켜고, 캐릭터 선택 화면의 애드온 목록에서 `W.I.H`를 켠다.
4. 접속하면 저장이 있을 때는 사냥 띠가 바로 뜬다. 처음이면 채팅창에 `/wih`를 입력해 진영과 첫 영웅을 고른다.

## 가장 먼저 확인해 주면 좋은 것: 3D 모델

캐릭터를 클라이언트의 3D 모델로 보여 주도록 만들었지만, **모델이 실제로 보이는지는 게임에서만 알 수 있다.** 아래를 알려 주면 된다.

1. 사냥 띠에서 영웅과 몬스터가 **캐릭터 모델**로 보이는가, **네모 아이콘**으로 보이는가.
   - 네모 아이콘으로 보이면: 모델 불러오기가 실패해서 자동으로 바뀐 것이다. 그 사실만 알려 주면 된다.
2. 모델이 보인다면
   - 영웅이 **오른쪽**(적 쪽)을, 적이 **왼쪽**을 보고 있는가. 반대라면 설정 → "방향 뒤집기"를 켠다.
   - 공격할 때, 스킬을 쓸 때, 쓰러질 때 **동작이 바뀌는가.**
   - 크기가 띠에 맞는가(너무 크거나 작거나, 머리나 발이 잘리지 않는가).
   - 화면이 끊기는가. 끊기면 설정 → "모델 수"를 낮춰 본다.
3. 설정 → **"모델 점검"**: 영웅·보스·일반 몬스터의 모델을 한 쪽에 12개씩 보여 준다. 모델 번호를 기억에 의존해 적었기 때문에, 엉뚱한 모델이 나오거나 비어 있는 칸이 있을 것이다. 영웅 3쪽만이라도 캡처해 주면 번호를 고친다(번호가 붉게 나오면 그 번호의 모델이 없는 것이다).

## 그다음으로 확인해 주면 좋은 것

오류가 나면 채팅창에 `W.I.H 오류:`로 시작하는 붉은 줄이 뜬다. 그 줄을 그대로 알려 주면 된다. 설정 화면의 "최근 오류"에도 남는다.

1. 사냥 띠와 메뉴 창이 시안(`docs/design/mockups/ui-01-strip-and-menu.png`)과 비슷하게 보이는가. 다른 곳은 어디인가.
2. 영웅 화면: 가운데 캐릭터, 양옆의 장비 10칸, 아래의 전투력, 오른쪽의 스킬·패시브·능력치가 제자리에 있는가.
3. 영웅 화면의 장비 칸을 누르면 가방으로 넘어가고, 가방에서 아이템을 오른쪽 클릭하면 장착되는가.
4. 띠를 옮기고 폭을 바꾼 뒤 `/reload`해도 그 자리에 있는가.
5. 글자가 칸을 넘치거나 겹치는 곳, 눌러도 반응이 없는 버튼, 물음표로 나오는 아이콘이 있는가.

**화면마다 캡처 한 장씩**(사냥 띠, 영웅, 가방, 모델 점검)이 가장 도움이 된다.

## 들어 있는 것과 없는 것

| 들어 있음 | 아직 없음 |
|---|---|
| 영웅 30명과 스킬 180개, 스킬 트리, 장착 스킬, 전투력 표시 | 큐브(합성·제작·장식 등 10기능) |
| 편성(룬으로 최대 5칸) | 펫, 유물 |
| 액트 1~3의 던전 27구간과 보스 149종, 레이드 3종, 난이도 4단계 | 원정(줄구룹·안퀴라즈), 낙스라마스 |
| 장비 33종류(2,600여 개), 가방, 장착, 연금술(팔기) | 오프라인 보상 |
| 보물상자(드롭, 보관, 개봉, 자동 개봉 룬) | 고유 능력치가 붙은 장비 |
| 룬 200노드, 저장·백업·초기화 | 룬 트리 그림(지금은 목록) |

- 편성·스테이지·성장·설정 탭은 색과 창 구조만 새것이고 안의 배치는 이전 그대로다(시안에 없던 화면). 영웅·가방 탭과 사냥 띠의 방향이 맞으면 같은 방식으로 다듬는다.
- 난이도는 아직 조정 전이다. 원작보다 어렵거나 쉬운 구간이 있다.
